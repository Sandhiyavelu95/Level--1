Event Feedback Hub

A simple, responsive website for collecting and managing event feedback from attendees. Built with HTML and CSS as a Level 1 project.

🌟 Features:
Home Page – Overview of the platform, stats, and how it works
Events Page – Browse a list of upcoming and past events
Feedback Page – Submit ratings and comments for an attended event
Clean, responsive UI with a consistent header, top bar, and footer across all pages


📁 Project Structure
├── index.html      # Home page
├── events.html     # Events listing page
├── feedback.html   # Feedback submission form
└── css/
    └── styles.css  # Stylesheet for all pages
    
🛠️ Built With:
HTML5
CSS3

🚀 Getting Started
Download or clone the project files.
Make sure styles.css is placed inside a css/ folder (as referenced in the HTML files).
Open index.html in your browser to view the site.

📄 Pages:
index.html -	Landing page introducing the platform
events.html	- List of events with a "Give Feedback" link for each
feedback.html	- Form to submit name, email, event, rating, and comments

📌 Notes:
This is a front-end only project (Level 1) — the feedback form does not yet submit data to a server/database. That will be added in a future level.
